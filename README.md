# JobFinder — Job Portal

A responsive college mini-project job portal landing page built with HTML, CSS and vanilla JavaScript.

## Features

- Responsive JobFinder homepage
- Job search by keyword, location and category
- Popular search shortcuts
- Job cards with save/bookmark interaction
- Top companies section
- Job categories
- Login/Register demo modal
- Job application demo interaction
- Dark/light mode
- Mobile navigation
- No backend required for the demo

## Run locally

Open `index.html` in a browser.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts (Inter)

## Project

Built as a college mini project and intended to be extended with a Java/.NET backend and SQL database.
